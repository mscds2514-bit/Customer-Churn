# Customer-Churn

Customer Churn Prediction



\- This project predicts whether a telecom customer is likely to churn or continue using the service.

\- It uses the Telco Customer Churn dataset containing customer details such as tenure, contract, services, and billing information.

\- The problem is a supervised machine learning \*\*binary classification\*\* problem, where the target is `Churn Label`.

\- The data is preprocessed and a \*\*Logistic Regression\*\* model is used to train and predict customer churn.

\- The prediction can help telecom companies identify high-risk customers and take actions to improve customer retention.
